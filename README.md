# Resume Builder Application

A full-stack Resume Builder platform that allows users to create, customize, download, and manage resumes.  
Built using **Spring Boot + MongoDB** for backend APIs and **Vue 3 + Vite + TailwindCSS** for the frontend.

---

## 🚀 Tech Stack

### Backend
- Spring Boot 3
- MongoDB
- Spring Security + JWT Authentication
- Cloudinary (File Uploads)
- Razorpay Integration
- Email Service (Spring Mail)
- Actuator for Monitoring

### Frontend
- Vue 3 + TypeScript
- Vite
- TailwindCSS
- Pinia (State Management)
- Vue Router

---

## ▶️ Running the Project

### Backend
```bash
# Navigate to backend folder
cd backend

# Build and run
mvn spring-boot:run


The backend runs on: **[http://localhost:8080](http://localhost:8080)**

### Frontend

```bash
# Navigate to frontend folder
cd frontend

npm install
npm run dev
```

The app runs on: **[http://localhost:5173](http://localhost:5173)**
